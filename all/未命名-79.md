```mermaid
flowchart TD
    A[开始执行积分重置任务<br/>每月1号0点执行] --> B[初始化任务参数<br/>当前时间、批次大小等]
    B --> C[计算当前重置周期标识<br/>如: 2024-03]
    C --> D[统计需要重置的订阅总数<br/>查询t_user_subscriptions]
    
    D --> E{是否有订阅需要重置?}
    E -->|否| F[记录日志: 无订阅需要重置]
    F --> Z[任务结束]
    
    E -->|是| G[开始分批处理订阅记录]
    G --> H[查询一批活跃订阅记录<br/>批次大小: 1000]
    
    H --> I{批次中是否有订阅?}
    I -->|否| Y[所有订阅处理完成]
    Y --> AA[统计并记录任务执行结果]
    AA --> Z
    
    I -->|是| J[遍历批次中的每个订阅]
    J --> K[判断订阅是否需要重置]
    K --> L{"""
    重置条件检查:
    1. status = 'active'
    2. next_reset_time <= 当前时间
    3. 不是免费试用等特殊状态
    """}
    
    L -->|不需要重置| BB[跳过此订阅]
    L -->|需要重置| M[根据plan_id获取订阅计划配置]
    
    M --> N[从t_subscription_plans获取积分配额]
    N --> O["""
    获取计划配置:
    basic_points_per_month
    premium_points_per_month
    重置周期天数
    """]
    
    O --> P[获取用户当前积分状态]
    P --> Q[从t_user_points获取当前积分]
    Q --> R["""
    当前积分构成:
    - basic_points (总基础积分)
    - premium_points (总高级积分)  
    - basic_system_points (系统基础积分)
    - premium_system_points (系统高级积分)
    """]
    
    R --> S[计算奖励积分(永久保留)]
    S --> T["""
    奖励积分计算:
    basic_reward = basic_points - basic_system_points
    premium_reward = premium_points - premium_system_points
    """]
    
    T --> U[计算重置后的积分]
    U --> V["""
    重置后积分:
    new_basic_system = plan.basic_points_per_month
    new_premium_system = plan.premium_points_per_month
    new_basic_total = basic_reward + new_basic_system
    new_premium_total = premium_reward + new_premium_system
    """]
    
    V --> W[开始数据库事务]
    W --> X[更新用户积分表 t_user_points]
    X --> Y1["""
    更新字段:
    - basic_points = new_basic_total
    - premium_points = new_premium_total
    - basic_system_points = new_basic_system
    - premium_system_points = new_premium_system
    - last_reset_date = 当前时间
    - current_reset_cycle = 周期标识
    """]
    
    Y1 --> Y2[更新用户订阅表 t_user_subscriptions]
    Y2 --> Y3["""
    更新next_reset_time:
    根据billing_cycle计算下次重置时间
    - monthly: +30天
    - yearly: +365天
    """]
    
    Y3 --> Y4[记录基础积分重置交易]
    Y4 --> Y5["""
    插入t_point_transactions (基础积分):
    - transaction_type = 'system_reset'
    - point_type = 'basic'
    - amount = new_basic_system - old_basic_system
    - source_type = 'system_grant'
    - target_account = 'system'
    - is_resettable = true
    - reset_cycle = 当前周期
    """]
    
    Y5 --> Y6[记录高级积分重置交易]
    Y6 --> Y7["""
    插入t_point_transactions (高级积分):
    - transaction_type = 'system_reset'  
    - point_type = 'premium'
    - amount = new_premium_system - old_premium_system
    - source_type = 'system_grant'
    - target_account = 'system'
    - is_resettable = true
    - reset_cycle = 当前周期
    """]
    
    Y7 --> Y8[提交事务]
    Y8 --> Y9{事务是否成功?}
    
    Y9 -->|失败| Y10[回滚事务]
    Y10 --> Y11[记录失败订阅]
    Y11 --> Y12[记录错误日志]
    Y12 --> BB
    
    Y9 -->|成功| Y13[记录成功处理数量]
    Y13 --> Y14[更新处理进度]
    Y14 --> BB
    
    BB --> CC[处理下一个订阅]
    CC --> DD{当前批次是否处理完?}
    
    DD -->|否| J
    DD -->|是| EE{是否还有未处理的批次?}
    EE -->|是| H
    EE -->|否| Y
```
