```mermaid
flowchart TD
    A[开始执行积分重置任务<br/>每月1号0点执行] --> B[初始化任务参数<br/>当前时间、批次大小等]
    B --> C[计算当前日期<br/>格式: YYYY-MM-DD]
    C --> D[统计需要重置的用户总数<br/>基于订阅表查询]
    
    D --> E{是否有用户需要重置?}
    E -->|否| F[记录日志: 无用户需要重置]
    F --> Z[任务结束]
    
    E -->|是| G[开始分批处理用户]
    G --> H[查询一批需要重置的用户订阅<br/>批次大小: 1000]
    
    H --> I{批次中是否有用户?}
    I -->|否| Y[所有用户处理完成]
    Y --> AA[统计并记录任务执行结果]
    AA --> Z
    
    I -->|是| J[遍历批次中的每个用户订阅]
    J --> K[计算该用户的重置周期]
    K --> L{"""
    重置条件判断:
    1. status = 'active'
    2. 根据start_time和billing_cycle计算是否到重置时间
    3. monthly: 每月1号重置
    4. yearly: 每年订阅开始月份的1号重置
    """}
    
    L -->|不需要重置| BB[跳过此用户]
    L -->|需要重置| M[根据plan_id获取订阅计划配置]
    
    M --> N[从t_subscription_plans获取积分配额]
    N --> O["""
    获取计划配置:
    - basic_points_per_month
    - premium_points_per_month
    - plan_type (区分免费/付费)
    """]
    
    O --> P[检查用户积分记录是否存在]
    P --> Q{用户积分记录存在?}
    
    Q -->|否| R[创建初始积分记录]
    R --> R1["""
    创建t_user_points记录:
    - user_id = 当前用户ID
    - basic_points = 0
    - premium_points = 0
    - basic_system_points = 0
    - premium_system_points = 0
    - last_reset_date = 0
    """]
    R1 --> S
    
    Q -->|是| S[获取用户当前积分状态]
    S --> T["""
    从t_user_points获取:
    - basic_points (总基础积分)
    - premium_points (总高级积分)
    - basic_system_points (系统基础积分)
    - premium_system_points (系统高级积分)
    - last_reset_date (上次重置时间)
    """]
    
    T --> U[计算奖励积分(永久保留)]
    U --> V["""
    奖励积分计算:
    basic_reward = basic_points - basic_system_points
    premium_reward = premium_points - premium_system_points
    
    注意：奖励积分不能为负数
    如果为负，则设为0
    """]
    
    V --> W[计算新的系统积分配额]
    W --> X["""
    新系统积分:
    new_basic_system = plan.basic_points_per_month
    new_premium_system = plan.premium_points_per_month
    
    重置后总积分:
    new_basic_total = basic_reward + new_basic_system
    new_premium_total = premium_reward + new_premium_system
    """]
    
    X --> Y1[开始数据库事务]
    Y1 --> Y2[更新用户积分表]
    Y2 --> Y3["""
    更新t_user_points:
    - basic_points = new_basic_total
    - premium_points = new_premium_total
    - basic_system_points = new_basic_system
    - premium_system_points = new_premium_system
    - last_reset_date = 当前时间戳
    - current_reset_cycle = 当前周期(如2024-03)
    """]
    
    Y3 --> Y4[记录基础积分重置交易]
    Y4 --> Y5["""
    插入t_point_transactions (基础积分):
    - transaction_id = UUID
    - user_id = 用户ID
    - transaction_type = 'earn' 
    - point_type = 'basic'
    - amount = new_basic_system
    - source_type = 'system_grant'
    - target_account = 'system'
    - feature_name = 'monthly_reset'
    - before_system_points = old_basic_system
    - after_system_points = new_basic_system
    - before_reward_points = basic_reward
    - after_reward_points = basic_reward
    - before_points = old_basic_total
    - after_points = new_basic_total
    - is_resettable = true
    - reset_cycle = 当前周期
    """]
    
    Y5 --> Y6{高级积分是否大于0?}
    Y6 -->|是| Y7[记录高级积分重置交易]
    Y6 -->|否| Y9
    
    Y7 --> Y8["""
    插入t_point_transactions (高级积分):
    - transaction_type = 'earn'
    - point_type = 'premium' 
    - amount = new_premium_system
    - 其他字段类似基础积分
    """]
    Y8 --> Y9
    
    Y9 --> Y10[提交事务]
    Y10 --> Y11{事务是否成功?}
    
    Y11 -->|失败| Y12[回滚事务]
    Y12 --> Y13[记录失败用户和错误信息]
    Y13 --> Y14[增加失败计数]
    Y14 --> BB
    
    Y11 -->|成功| Y15[记录成功处理]
    Y15 --> Y16[增加成功计数]
    Y16 --> Y17[记录处理日志]
    Y17 --> BB
    
    BB --> CC[处理下一个用户]
    CC --> DD{当前批次是否处理完?}
    
    DD -->|否| J
    DD -->|是| EE{是否还有未处理的批次?}
    EE -->|是| H
    EE -->|否| Y
```
