```mermaid

stateDiagram-v2
    [*] --> local_mode: 初始状态
    
    local_mode --> transition_to_online: 用户请求切换到在线模式
    transition_to_online --> local_mode: 切换失败
    transition_to_online --> online_mode: 上传数据成功
    
    online_mode --> transition_to_local: 用户请求切换到本地模式
    transition_to_local --> online_mode: 切换失败
    transition_to_local --> local_mode: 下载数据并清空服务器成功
    
    online_mode --> OFFLINE: 网络断开
    OFFLINE --> online_mode: 网络恢复
    
    transition_to_online --> error: 发生异常
    transition_to_local --> error: 发生异常
    error --> local_mode: 恢复至安全状态

```
