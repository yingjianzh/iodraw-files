```mermaid
flowchart TD
    Start([开始文件解密]) --> ReadFile[解密]
    ReadFile --> DecryptionSuccess{解密成功?}
    
    DecryptionSuccess -->|否| A[数据恢复失败]
    DecryptionSuccess -->|是| DecompressData[解压缩数据]
    
    DecompressData --> DecompressionSuccess{解压成功?}
    DecompressionSuccess -->|否| HandleDecompressError[处理解压错误]
    DecompressionSuccess -->|是| ParseJSON[解析JSON数据]
    
    ParseJSON --> JSONValid{JSON格式有效?}
    JSONValid -->|否| HandleParseError[处理解析错误]
    JSONValid -->|是| ReturnDecryptedData[返回解密数据]
    
    ReturnDecryptedData --> End([解密完成])
    
    DecryptionError --> LogError[记录错误信息]
    HandleDecryptError --> LogError
    HandleDecompressError --> LogError
    HandleParseError --> LogError
    
    A --> End[]
    ThrowException --> End
```
