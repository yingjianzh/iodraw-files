```mermaid
flowchart TD
    Start([开始恢复]) --> SelectSource{选择备份来源}
    SelectSource -->|本地文件| BrowseLocal[浏览本地备份文件]
    SelectSource -->|Google Drive| AuthGoogle[授权Google Drive]
    
    BrowseLocal --> LoadBackup[加载备份文件]
    AuthGoogle --> ListGDriveBackups[列出Google Drive备份]
    ListGDriveBackups --> SelectBackup[选择备份文件]
    SelectBackup --> DownloadBackup[下载备份文件]
    DownloadBackup --> LoadBackup
    
    LoadBackup --> ValidateStructure[验证备份结构]
    ValidateStructure --> ValidationResult{验证结果}
    
    ValidationResult -->|失败| ShowError[显示错误信息]
    ShowError --> End([结束恢复])
    
    ValidationResult -->|成功| ExtractManifest[提取清单文件]
    ExtractManifest --> DecryptManifest[解密清单文件]
    DecryptManifest --> VerifyUser[验证用户身份]
    
    VerifyUser --> UserMatch{用户匹配?}
    UserMatch -->|否| ShowUserError[显示用户不匹配错误]
    ShowUserError --> End
    
    UserMatch -->|是| CheckIntegrity[检查备份完整性]
    CheckIntegrity --> IntegrityResult{完整性检查}
    
    IntegrityResult -->|失败| ShowIntegrityError[显示完整性错误]
    ShowIntegrityError --> End
    
    IntegrityResult -->|成功| CheckMode{当前模式}
    CheckMode -->|在线模式| ConfirmServerRestore[确认覆盖服务器数据]
    CheckMode -->|本地模式| ConfirmLocalRestore[确认覆盖本地数据]
    
    ConfirmServerRestore --> UserConfirm1{用户确认?}
    UserConfirm1 -->|否| CancelRestore[取消恢复]
    UserConfirm1 -->|是| PrepareServerRestore[准备服务器恢复]
    
    ConfirmLocalRestore --> UserConfirm2{用户确认?}
    UserConfirm2 -->|否| CancelRestore
    UserConfirm2 -->|是| PrepareLocalRestore[准备本地恢复]
    
    PrepareServerRestore --> InitRestore[初始化恢复过程]
    PrepareLocalRestore --> InitRestore
    
    InitRestore --> ProcessRestore[处理恢复]
    
```
