```mermaid
flowchart TD
    Start([开始本地存储]) --> CreateContainer[创建备份容器]
    CreateContainer --> AddMetadata[添加元数据]
    AddMetadata --> ProcessFilesToSave[处理待保存文件]
    
    ProcessFilesToSave --> NextFile{还有文件?}
    NextFile -->|否| FinalizeBackup[完成备份]
    NextFile -->|是| WriteFile[写入文件]
    
    WriteFile --> VerifyWrite{写入成功?}
    VerifyWrite -->|是| UpdateProgress[更新进度]
    VerifyWrite -->|否| HandleError[处理错误]
    
    HandleError --> ErrorRecoverable{可恢复?}
    ErrorRecoverable -->|是| RetryWrite[重试写入]
    ErrorRecoverable -->|否| AbortBackup[中止备份]
    
    RetryWrite --> WriteFile
    UpdateProgress --> NextFile
    
    FinalizeBackup --> AddDigitalSignature[添加数字签名]
    AddDigitalSignature --> SavePasswordHint[保存密码提示(可选)]
    SavePasswordHint --> TriggerDownload[触发下载]
    TriggerDownload --> End([结束])
    
    AbortBackup --> CleanupTemp[清理临时文件]
    CleanupTemp --> NotifyUser[通知用户失败]
    NotifyUser --> End
```
