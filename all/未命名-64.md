```mermaid
flowchart TD
    %% 主要节点定义
    Start[创建者拥有已发布应用]
    ShareAction[创建者点击分享应用]
    GenerateLink[生成应用体验链接]
    ShareToUser[通过各种渠道分享链接]
    OpenLink[用户打开分享链接]
    TryApp[用户试用应用\n可交互/可缩放/数据不保存]
    KeepApp[用户点击"保留该应用"]
    CheckLogin{用户是否已登录?}
    LoginRegister[用户注册/登录]
    SaveToSpace[保存应用到用户空间]
    AddToRepo[在用户应用仓库中添加该应用]
    End[完成应用获取]
    Refresh[刷新页面\n数据清除]
    Leave[用户离开页面]

    %% 流程连接
    Start --> ShareAction
    ShareAction --> GenerateLink
    GenerateLink --> ShareToUser
    ShareToUser --> OpenLink
    OpenLink --> TryApp
    
    TryApp --> KeepApp
    TryApp -- 刷新页面 --> Refresh
    Refresh --> TryApp
    TryApp -- 不保留 --> Leave
    
    KeepApp --> CheckLogin
    
    CheckLogin -- 否 --> LoginRegister
    LoginRegister --> SaveToSpace
    
    CheckLogin -- 是 --> SaveToSpace
    SaveToSpace --> AddToRepo
    AddToRepo --> End
    
    %% 样式定义
    classDef start fill:#d0f0c0,stroke:#333,stroke-width:2px
    classDef process fill:#f5f5f5,stroke:#333,stroke-width:1px
    classDef decision fill:#ffcc99,stroke:#333,stroke-width:1px,shape:diamond
    classDef end fill:#f9cedf,stroke:#333,stroke-width:2px
    
    %% 应用样式
    class Start,ShareAction start
    class GenerateLink,ShareToUser,OpenLink,TryApp,LoginRegister,SaveToSpace,AddToRepo,Refresh process
    class CheckLogin decision
    class End,Leave end
```
