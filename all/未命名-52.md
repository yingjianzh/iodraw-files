```mermaid
flowchart TD
    Start([从服务器收集数据]) --> PrepareAPIRequests[准备API请求]
    PrepareAPIRequests --> RequestUserData[请求用户数据摘要]
    
    RequestUserData --> DataSummaryReceived{收到数据摘要?}
    DataSummaryReceived -->|否| RetryRequest[重试请求]
    DataSummaryReceived -->|是| AnalyzeSummary[分析数据摘要]
    
    RetryRequest --> RetryCount{重试次数<3?}
    RetryCount -->|是| RequestUserData
    RetryCount -->|否| ShowAPIError[显示API错误]
    
    ShowAPIError --> End([结束])
    
    AnalyzeSummary --> SetupDataFetch[设置数据获取计划]
    
    SetupDataFetch --> PlanFetchStrategy[规划获取策略]
    
    PlanFetchStrategy --> FetchTableData[获取表数据]
    
    subgraph DataFetching [数据获取过程]
        A[处理下一个表] --> B{还有表需处理?}
        B -->|否| ExitFetching[完成数据获取]
        B -->|是| C[估计表大小]
        
        C --> D{表大小策略}
        D -->|小(<5MB)| E1[单次API请求]
        D -->|中(5-50MB)| E2[分页API请求]
        D -->|大(>50MB)| E3[块化API请求]
        
        E1 --> F1[处理完整响应]
        E2 --> F2[处理分页响应]
        E3 --> F3[处理块响应]
        
        F2 --> G1{还有更多页?}
        G1 -->|是| E2
        G1 -->|否| H[合并分页结果]
        
        F3 --> G2{还有更多块?}
        G2 -->|是| E3
        G2 -->|否| H
        
        F1 --> I[格式化为统一结构]
        H --> I
        
        I --> J[添加到结果集]
        J --> A
    end
    
    FetchTableData --> DataFetching
    
    DataFetching --> ValidateData[验证数据完整性]
    ValidateData --> FormatResults[格式化最终结果]
    FormatResults --> ReturnCollected[返回收集的数据]
    
    ReturnCollected --> End
```
