flowchart TD
    A[开始同步] --> B[获取change_tracker表中pending状态的数据]
    B --> C{按entity_type分类处理}
    
    C -->|space| D1[根据canvas_id查询空间表数据]
    C -->|component| D2[根据component_id查询组件表数据]
    C -->|instance| D3[根据component_id和instance_id查询组件实例表数据]
    
    D1 --> E1[获取表中所有记录]
    D2 --> E1
    D3 --> E1
    
    E1 --> E2[进行hash计算]
    
    
    E2 --> I1{查询content_hash_records表中是否有对应实体记录}
    I1 -->|没有记录| K[执行上传数据到云端]
    I1 -->|有记录| I2{计算的hash与content_hash_records中的_hash比较}
    I2 -->|相同| J[已同步,无需上传]
    I2 -->|不同| K
    
    K --> L[上传成功]
    L --> M1{是否首次上传}
    M1 -->|是| M2[创建新的content_hash_records记录]
    M1 -->|否| M3[更新现有content_hash_records记录的content_hash]
    
    M2 --> N[更新change_tracker表中对应记录状态为completed]
    M3 --> N
    
    J --> N
    
    N --> O{是否还有pending记录}
    O -->|是| B
    O -->|否| P[同步完成]
    
    K --> Q[上传失败]
    Q --> R[更新change_tracker表状态为error]
    R --> S[增加retry_count]
    S --> T{重试次数是否超限}
    T -->|是| U[同步失败]
    T -->|否| B
    
    U --> P
