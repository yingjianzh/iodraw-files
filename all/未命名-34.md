```mermaid
graph TD
    subgraph 前端
        A[UI层] -->|监听数据变更| B(数据变更触发器)
        B -->|触发同步| C[同步状态管理器]
        C -->|轮询/WebSocket| D[心跳模块]
        A -->|用户操作| E[数据导入/导出UI]
    end

    subgraph 后端(Golang)
        F[API网关] -->|路由请求| G[业务逻辑层]
        G --> H[数据存储引擎]
        G --> I[云存储适配器]
        G --> J[加密/混淆处理器]
        H -->|存储| K[(本地缓存数据库)]
        I -->|读写| L[第三方云存储]
        J -->|加密/签名| M[安全模块]
        G -->|冲突检测| N[同步日志服务]
        N -->|记录变更| O[(同步日志数据库)]
        D -->|心跳状态| P[设备状态管理器]
    end

    subgraph 用户云存储
        L[Google Drive/OneDrive/iCloud]
    endsequenceDiagram
    participant User as 用户操作
    participant Frontend as 前端
    participant AppServer as 后端
    participant Cloud as 云存储

    User->>Frontend: 修改组件数据
    Frontend->>AppServer: 发送数据变更事件（含组件ID、实例ID）
    AppServer->>AppServer: 
        Note over AppServer: 执行以下原子操作：<br/>1. 更新本地缓存数据库<br/>2. 生成数据快照<br/>3. 计算新Hash(SHA-256)
    AppServer->>Cloud: 上传加密数据包（格式示例）：
        {
          "data": "AES-256加密的组件数据",
          "hash": "a1b2c3",
          "signature": "HMAC-SHA256(...)",
          "user_id": "xxx"
        }
    Cloud-->>AppServer: 返回存储路径
    AppServer->>AppServer: 记录同步日志（时间戳、操作类型、冲突标记）
    AppServer->>Frontend: 返回同步结果（成功/冲突）
```
