```mermaid
sequenceDiagram
    participant ChatAPI as Chat API
    participant LLMProxy as LLM Proxy
    participant ConnMgr as Connection Manager
    participant ReqBuilder as Request Builder
    participant WSConn as WebSocket Connection
    participant LLMServer as LLM Server

    ChatAPI->>LLMProxy: SendUserMessage(conv_id, content, providers)
    
    LLMProxy->>ConnMgr: GetOrCreate(ctx, conv_id)
    
    alt 连接不存在
        ConnMgr->>LLMServer: WebSocket Dial
        LLMServer-->>ConnMgr: 连接成功
        ConnMgr->>ConnMgr: 启动 readLoop/writeLoop/heartbeatLoop
        ConnMgr->>ConnMgr: 存入 connections map
    end
    
    ConnMgr-->>LLMProxy: 返回 WSConnection
    
    LLMProxy->>ReqBuilder: BuildUserMessage(conv_id, content, providers)
    ReqBuilder-->>LLMProxy: 返回 *WSMessage
    
    LLMProxy->>LLMProxy: sendMessage(conn, msg)
    LLMProxy->>WSConn: SendChan <- msg
    
    Note over WSConn: writeLoop 处理
    WSConn->>LLMServer: WebSocket Write
    
    LLMProxy-->>ChatAPI: 返回 nil
```
