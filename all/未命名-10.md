```mermaid
Task Manager
│
├─ Event Handler Module（事件处理模块）
│  ├─ 接收 Event Manager 的通知
│  ├─ 提取 Task/Todo 信息
│  ├─ 更新内存状态
│  └─ 触发持久化
│
├─ State Management Module（状态管理模块）
│  ├─ 维护 Task 状态机
│  ├─ 维护 Todo 状态机
│  ├─ 验证状态转换合法性
│  └─ 计算任务进度
│
├─ Persistence Module（持久化模块）
│  ├─ 写入 MongoDB（Task 集合）
│  ├─ 写入 MongoDB（Todo 集合）
│  ├─ 更新状态字段
│  └─ 批量操作优化
│
├─ Query Module（查询模块）
│  ├─ 根据 task_id 查询
│  ├─ 根据 conversation_id 查询
│  ├─ 根据用户查询（分页）
│  └─ 聚合统计
│
└─ Cache Module（缓存模块，可选）
   ├─ 缓存热点 Task 到 Redis
   ├─ 缓存失效策略
   └─ 缓存更新策略
```
