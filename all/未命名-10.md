sequenceDiagram
    participant ChatAPI as Chat API
    participant SubMod as Event Manager<br/>(Subscription Module)
    participant ProcMod as Event Manager<br/>(Processing Module)
    participant Builder as Event Manager<br/>(MessageBuilder)
    participant Counter as Event Manager<br/>(Event Counter)
    participant DistribMod as Event Manager<br/>(Distribution Module)

    Note over LLMProxy: LLM返回SSE流

    ProcMod->>Builder: 更新 MessageBuilder<br/>Content += "你好"

    ChatAPI->>ChatAPI: 从 eventChan 接收 event

    Note over LLMProxy: 继续流式输出

    ProcMod->>DistribMod: 分发 Event(id=2)
    DistribMod->>ChatAPI: eventChan <- event
    ProcMod->>Builder: last_pushed_id=2
    
    ChatAPI->>ChatAPI: 写入 SSE
    
    Note over LLMProxy: LLM 流结束
    
    LLMProxy->>ProcMod: ProcessLLMEvent<br/>(finish_reason: "stop")

    ProcMod->>Builder: 清理 Builder
    
    ProcMod->>DistribMod: 分发 DONE Event
    DistribMod->>ChatAPI: eventChan <- done_event
    
    ChatAPI->>ChatAPI: 写入 SSE [DONE]
    ChatAPI->>SubMod: Unsubscribe(conv_123)
    SubMod->>SubMod: 关闭 eventChan<br/>从 map 移除
