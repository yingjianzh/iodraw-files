```mermaid

stateDiagram-v2
    [*] --> unpublished: 创建组件(默认状态)
    unpublished --> publishing: 用户点击发布
    publishing --> published: 发布成功(MQ事件完成)
    publishing --> unpublished: 发布失败(crypto-server回调失败)
    
    published --> unpublishing: 用户点击下架
    unpublishing --> unpublished: 下架成功(MQ事件完成)
    unpublishing --> published: 下架失败(crypto-server回调失败)
    
    note right of unpublished
        未发布状态(默认)
        组件创建后的初始状态
        或发布失败/下架成功后的状态
    end note
    
    note right of publishing
        发布中
        等待crypto-server处理
    end note
    
    note right of published
        已发布
        NFT已创建并激活
    end note
    
    note right of unpublishing
        下架中
        等待crypto-server处理
    end note

```
