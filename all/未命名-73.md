```mermaid

sequenceDiagram
    participant User as 用户
    participant Frontend as 前端
    participant Backend as 后端
    participant Twitter as Twitter API
    participant DB as 数据库


    User->>Frontend: 点击绑定Twitter
    Frontend->>Backend: GET /w3/wallet/social/twitter/auth
    Backend->>DB: 生成OAuth state
    Backend->>Backend: 构建Twitter OAuth URL
    Backend->>Frontend: 返回授权URL
    Frontend->>User: 重定向到Twitter授权页面
    
    User->>Twitter: 授权应用访问
    Twitter->>Backend: 回调 /w3/wallet/social/twitter/callback?code=xxx&state=xxx
    Backend->>DB: 验证state有效性
    Backend->>Twitter: 使用code换取access_token
    Twitter->>Backend: 返回access_token和用户信息
    Backend->>DB: 检查Twitter账号是否已被绑定
    
    alt Twitter账号未被绑定
        Backend->>DB: 保存绑定信息
        Backend->>Backend: 发放绑定奖励
        Backend->>DB: 记录奖励发放
        Backend->>Frontend: 绑定成功
        Frontend->>User: 显示绑定成功和奖励信息
    else Twitter账号已被绑定
        Backend->>Frontend: 返回绑定失败（账号已被使用）
        Frontend->>User: 显示错误信息
    end

```
